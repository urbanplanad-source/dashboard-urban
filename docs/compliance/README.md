# 의료광고 컴플라이언스 자료실

이 폴더는 병원/의료 콘텐츠를 작성할 때 참고할 보건복지부 의료광고 가이드 원본과, Codex 및 검수 서브에이전트가 빠르게 사용할 운영용 체크리스트를 함께 보관한다.

## 원본 PDF

| 파일 | 원본 자료 | 기준 |
|------|-----------|------|
| `source-pdfs/healthy-medical-ads-2nd.pdf` | 건강한 의료광고, 우리가 함께 만들어요! 유형별 의료광고 사례 및 체크리스트 2판 | 우선 기준. 2024.12 안내문이 포함된 개정판 |
| `source-pdfs/medical-ad-cases-checklist-guide.pdf` | 건강한 의료광고, 우리가 함께 만들어요! 유형별 의료광고 사례 및 체크리스트 | 보조 자료. 2020.07 안내문이 포함된 이전판 |

> 원본 PDF는 보존용이다. 매번 콘텐츠를 만들 때 PDF 전체를 프롬프트에 넣기보다 `medical-ad-review-guide.md`와 `medical-ad-checklist.json`을 먼저 읽고, 애매한 항목만 원본 PDF로 돌아가 확인한다.

## 운영 파일

| 파일 | 용도 |
|------|------|
| `medical-ad-review-guide.md` | 콘텐츠 작성자와 검수자가 읽는 한국어 운영 가이드 |
| `medical-ad-checklist.json` | 자동/반자동 검수에 쓰는 구조화 체크리스트 |
| `medical-ad-reviewer-prompt.md` | 초안 작성 후 서브에이전트에게 맡길 검수 프롬프트 |

## 기본 사용 순서

1. 거래처 브리프를 먼저 읽는다.
2. 의료/시술 콘텐츠라면 `medical-ad-review-guide.md`와 `medical-ad-checklist.json`을 함께 참고한다.
3. 초안을 작성한다.
4. `medical-ad-reviewer-prompt.md` 형식으로 별도 검수를 수행한다.
5. 검수 결과가 `PASS`가 아니면 초안을 수정하거나 사람 확인 대상으로 남긴다.
6. 대시보드 글 보관함에 저장할 때 memo에 `의료광고 검수: PASS/REVISE/HOLD`를 남긴다.

## 주의

- 이 자료는 법률 자문이 아니라 보건복지부 가이드 기반의 위험 점검 도구다.
- 개별 사안은 매체, 게시 위치, 병원 면허/전문과목, 실제 증빙자료에 따라 판단이 달라질 수 있다.
- 효과, 가격, 수상/인증, 전문성, 전후사진, 후기, 이벤트는 근거가 확인되지 않으면 `자료 확인 필요`로 남긴다.
