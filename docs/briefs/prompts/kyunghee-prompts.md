# 365경희부부한의원 피부클리닉 프롬프트팩

이 파일은 `docs/briefs/clients/kyunghee.md`를 실제 콘텐츠 제작에 쓰기 위한 작업 프롬프트 모음이다. 초안 작성 전에는 반드시 대시보드 `clientBrief&clientId=kyunghee`, 상세 위키, `docs/compliance/` 의료광고 기준을 함께 읽는다.

## 공통 입력값

아래 값은 요청마다 채워서 사용한다.

```text
매체:
목표:
주제/시술:
핵심 키워드:
지역 키워드:
가격/이벤트 사용 여부:
이미지/포스터 사용 여부:
톤:
분량:
반드시 넣을 문구:
피해야 할 문구:
```

## 공통 작성 규칙

* 병원명은 `365경희부부한의원 피부클리닉`으로 쓴다.
* 병원 정체성은 `한의원 피부클리닉`으로 명확히 한다.
* `피부과`는 검색 의도 설명용 키워드로만 제한적으로 사용한다.
* 치료효과 보장, 전후 차이 단정, 환자 후기처럼 보이는 1인칭 문체를 피한다.
* 가격, 체험가, 무제한, VAT, 이벤트 기간, 심의필, 이미지 사용권은 확인되지 않으면 본문에 직접 쓰지 않는다.
* 초안 뒤에 `의료광고 검수 메모`를 붙이고 `PASS`, `REVISE`, `HOLD` 중 하나로 자체 판정한다.

## 1. 블로그 초안

```text
365경희부부한의원 피부클리닉 블로그 글을 작성해줘.

먼저 아래 자료를 기준으로 읽고 판단해:
1. docs/briefs/clients/kyunghee.md
2. docs/compliance/medical-ad-review-guide.md
3. docs/compliance/medical-ad-checklist.json

입력값:
- 주제/시술:
- 핵심 키워드:
- 지역 키워드:
- 타깃:
- 분량:
- 가격/이벤트 노출 여부:

작성 조건:
- 환자 고민형 도입으로 시작해.
- 시술 원리, 고려 대상, 개인차, 주의사항, 사후관리, CTA 순서로 구성해.
- `피부과` 키워드를 쓰는 경우 검색 의도 설명으로만 써.
- 가격/체험가/무제한/VAT/이벤트 기간이 확인되지 않으면 `자료 확인 필요`로 남겨.
- 후기처럼 보이는 문체, 전후사진 효과 단정, 최저가/1등/완치 표현은 쓰지 마.

출력:
1. 제목 후보 5개
2. 본문 초안
3. 메타 설명 2개
4. 의료광고 검수 메모: PASS/REVISE/HOLD
5. 확인필요 목록
```

## 2. 홈페이지 섹션

```text

- 의료기관다운 차분한 설명형 톤으로 써.

- 심의필/전후사진/환자 사진/이벤트 포스터가 필요하면 `HOLD`로 표시해.

출력:

2. 리드문
3. 섹션별 문구
4. FAQ 4개
5. CTA
6. 검수 메모
```
